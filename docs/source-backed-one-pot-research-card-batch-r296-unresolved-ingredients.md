# r296：923 张来源执行卡的未展开配料标注收口

## 目标

本批不新增 canonical 菜谱，也不把研究起步量晋升为来源原方。目标是处理来源只给菜名、米种或器具，但没有公开完整配料构成的执行卡，避免用户把泛化占位词误解为必须采购的食材。

## 变更

- 目录版本：`source-backed-one-pot-v1-20260812-global-r296`
- 主目录：923 条（数量不变）
- 研究卡覆盖：923/923 有食材起步用量、液体指导、总时长和至少 3 步
- 明确清理“竹筒饭配料”“粉蒸配料”“菜/肉配料”等看似具体、实际无来源依据的泛名
- 9 条重点 identity/partial 卡改为只显示原文确认的米/器具，并在假设中写明“来源未展开、不能从菜名反推、不要自行添加”
- 全库所有仍含“待来源确认/按来源选取/具体构成待补”等名称的食材行，统一追加来源边界说明；研究起步量继续标为 `estimated`
- 傣族香竹饭、湘西苗族竹筒饭保留原文竹筒浸泡、米水比、蒸煮/火烤步骤；河豚卡继续安全阻断，不提供家庭处理步骤

## 边界

这些卡片是来源执行层的研究起步卡，不等于 923 条全部进入正式 Planner。正式 Planner 仍按来源合同、食材 taxonomy、比例 DSL、安全终点、厨房验证和旅程门禁运行；当前正式基础菜谱为 72 条。
