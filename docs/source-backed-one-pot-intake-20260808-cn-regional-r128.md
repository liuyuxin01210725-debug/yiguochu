## 证据与器具纪律

1. 政府名录或地方饮食清单只能证明名称与地域；没有具体正文时建议 `identity_verified`，不得补写克数、米水比例、时间、安全或电饭煲程序。
2. PDF 搜索摘要不能代替直接原文。肉油饭与蕨麻米饭本轮只列“待直接核验”，在完成下载、页码定位和归档摘要前，不得进入主 JSON 的可照做层。
3. 铜锅、瓦罉、罗锅、蒸笼、土灶与普通饭锅是不同器具事实。来源没有电饭煲转换证据时必须记 `not_adapted` 或 `source_limited`，不得推导程序、水位或防糊底规则。
4. 熟饭二次焗/炒、肉菜另锅后配白饭、面食/粥饭、甜点和小吃不能拼成一锅米饭主餐。
5. “肉类或菜蔬及作料”这种定义级表述只能支撑组合概念，不等于允许任意食材替换；后续每种替换必须另找 compatibility/来源证据。
