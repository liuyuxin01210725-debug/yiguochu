## 证据、器具与营养纪律

1. 官方文旅或节庆页面写出菜名，只能支撑名称/地域/语境；没有批量、液体、时间、流程或安全数字时，字段保持 `null`。
2. 甑、蒸笼、陶罐、砂锅、柴火和普通锅的原器具事实不能自动转换成电饭煲程序；没有直接适配来源时记 `not_adapted` 或 `source_limited`。
3. 乌饭、八宝饭、馏米等甜糯米或染色糯米食品与含肉/豆制品/蔬菜的日常均衡主餐是不同品类；不为扩充轮替池强行拼入蛋白或蔬菜。
4. 河蟹焖饭若未来进入 B 架，必须补直接配方来源、甲壳类处理和充分加热安全终点；盘锦官方品牌介绍本身不够。
