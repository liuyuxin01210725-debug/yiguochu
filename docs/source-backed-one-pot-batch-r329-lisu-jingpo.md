# r329：傈僳族手抓饭与景颇族蒸米饭的官方工艺边界

基线：`source-backed-one-pot-v1-20260810-global-r293` / 923 条。

本批没有新增 canonical，也没有把民族饮食概述升为可执行配方：

- 傈僳族手抓饭·拌饭：国家标准平台确认标准身份；中央电视台资料补充熟饭装入竹编簸箕、熟肉剁碎后与核桃粉、辣椒、蒜粉、食盐拌匀的传统边界。来源没有家庭批量、米水量、时间或电饭煲合同。
- 景颇族蒸米饭制作技艺（瑞丽）：瑞丽市政府名录确认项目身份；国家民族事务委员会资料补充景颇族以大米为主食，烹饪方式含煮、蒸、拌。该段不是瑞丽项目的定量配方。

两条仍显示研究卡的估算起步量、液体、时间和补充步骤；估算不写入执行合同。
