# r326：门巴族玉米饭来源边界片段

基线：`source-backed-one-pot-v1-20260810-global-r293` / 923 条。

本批只处理 `metok-menba-corn-rice`。国家民族事务委员会原页确认“玉米饭”是墨脱门巴族主食，并明确石锅是门巴族用于煮饭做菜的传统炊具；因此把这两条写入来源工艺/器具片段，供研究卡显示。原页没有玉米量、加水量、火力、时间、安全终点或电饭煲参数，故不写入 fixed_batch、liquid_contract、time_contract，也不把石锅转换成电饭煲合同。

来源：<https://www.neac.gov.cn/seac/ztzl/mbz/fsxg.shtml>

同时用回归断言确认本补丁没有把门巴族来源误写到 `yichang-cured-pork-braised-rice`。
