# 厂商官方电饭煲/电锅米饭主餐研究（2026-08-05）

本报告只记录厂商自有站点直接可访问的具名米饭主餐。事实是对页面的结构化摘要，不复制原文、图片或完整步骤；不等于项目已批准菜谱，也不把外锅水偷偷换算成普通电饭煲的米水比。

## 口径与访问证据

- `tier A`：厂商自有 HTML/PDF，页面同时出现具名菜、米/主料数量和器具执行信息；可作一手研究证据。
- `tier B`：仍是厂商自有页面，但至少一个关键合同（液体语义、程序时长、熟制终点或份量）不闭合；只能保留研究候选。
- `access`：本轮用 `web-access` 的 CDP 前置检查后，以页面原始 HTML（`curl -L`，HTTP 200）读取；没有用搜索摘要替代原页。访问日期 2026-08-05。
- 大同页面的“内锅水/高汤”和“外锅水”是两个变量：前者是食用/煮饭液体，后者是大同双锅电锅的加热控制量；下文分开记录。

## 去重基线

现有 `tools/data/rice-meal-catalog.v1.json`、`tools/data/rice-meal-collection.v1.json`、`tools/data/rice-cooker-source-evidence.v1.json` 与其生成审计文档已经包含：松下《什锦鸡饭》《鲜香菇饭》、九阳《咖喱鸡肉饭》《懒人焖饭》、象印《鲜蔬竹笋饭》《牛肉什锦饭》《番茄海鲜饭》、大同《上海菜饭》《麻油香菇盐麴鸡饭》及松下《香芋鸡煲仔饭》。本报告不再次列入这些条目，也不把同一 URL 的近邻菜名拆成新候选。
