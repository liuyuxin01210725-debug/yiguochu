## 证据、器具与营养边界

1. 具名页面只证明页面明确写出的身份、地域、食材、工艺或器具。没有固定批量、液体、时间和安全终点时，结构化字段保持 `null`，不从同类菜或搜索摘要补齐。
2. 砂煲、陶罐、瓦煲、土灶、甑/蒸笼、竹筒和公共大锅各自是独立事实域。原器具来源不能推出电饭煲水位、程序、防糊底或投料时机；需要单独适配证据或厨房验证。
3. “煮—炒—焗”、先煮鱼/鳝后焖饭、熟饭拌料、另锅炖肉等连续流程，必须在条目中保留阶段，不得为了增加 direct_one_pot 数量删掉前处理。
4. 纯碳水、甜味节庆米食、点心和身份名录即使有“饭/米饭”字样，也不自动进入 B 试做架；主餐候选至少要能从来源确认米饭与蛋白或蔬菜的关系，营养完整性仍需后续合同和厨房验证。
5. 食品安全终点只引用独立安全来源或原文明确事实；鱼、鳝、猪肉、禽肉、腊味等不因“焖熟”二字自动获得统一温度或时间。
