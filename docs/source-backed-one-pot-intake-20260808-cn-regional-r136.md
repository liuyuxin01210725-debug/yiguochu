## 证据、器具与营养纪律

1. 政府文旅页面明确写出菜名，只能支撑其写出的名称、地域、食材或高层技法；没有固定批量、液体、时间和安全终点时，字段保持 `null`。
2. 砂锅、瓦煲、土灶、甑子、竹筒与普通锅的事实不自动转换为电饭煲程序；没有直接适配来源时记 `not_adapted` 或 `source_limited`。
3. 熟饭拌料后焖、预处理米、另锅配菜、公共活动大锅饭和生米同锅焖饭分别建模；不能为了增加轮替数合并。
4. 粘糜子/纯小米/米+土豆等主要提供碳水的条目，必须保留营养边界，不因名称中出现“焖饭”就进入均衡主餐 B 架。
