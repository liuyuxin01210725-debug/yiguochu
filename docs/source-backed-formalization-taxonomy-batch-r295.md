# r295：明确禽肉切型的正式化审核映射

本批不新增菜名、不修改来源合同，也不把研究估算提升为正式 Planner 菜谱。只为来源卡中明确写出的禽肉切型补上审核器的受控 taxonomy 映射：

| 来源标签 | 受控 taxonomy | 处理原则 |
|---|---|---|
| 整只鸡腿、去骨雞腿排、帶皮雞腿肉、去骨雞腿肉 | `chicken-leg` | 标签明确指向鸡腿/鸡腿肉，不改变来源状态 |
| 去脂鸡腿肉、去骨去皮鸡胸、去骨去皮鸡胸肉 | `chicken-leg` / `chicken-breast` | 来源明确给出腿或胸的去脂/去皮切型 |
| 鸡块、鸡件、鸡扒 | `chicken-generic` | 只确认是鸡肉块/鸡扒，不擅自推断胸/腿部位 |

同批还关闭了明确状态的原料标签：`舞菇`、`舞茸`、`雪白菇` 归到既有生鲜 `mushroom-generic`；`越光米` 归到既有生米 `raw-rice`。`洋菇`、`五谷米`、`黑鲔鱼`、`火腿`、`盐鲭`、`大葉` 等仍保留缺口，避免把复合谷物、罐藏/腌制状态或未建档食材误合并。这些只是审核身份映射，不新增营养数值，也不改变来源用量。

这是审核映射，不是营养库新增，也不是跨机型比例规则。含“整鸡”“熟地方鸡腿肉”“鸡腿或整鸡腿”等状态或部位歧义的标签继续保留在缺口列表，不用别的条目代填。

验证：先运行专项测试确认上述标签仍为 taxonomy 缺口（RED），补入受控映射后专项 2/2 通过；后续重建正式化审查、staging 与目录门禁。比例 DSL、锅具适配、厨房观察和真实旅程仍未因此闭合，正式 Planner 仍保持 72 道。
