## 分类口径

- `direct_one_pot`：原文明确生米／米粥和主要配料在同一锅（或同一电锅内锅）完成；只记录原文器具，不把普通锅推导成电饭煲。
- `cooked_rice_second_cook`：原文先有熟饭，再炒、浇汁、拌合或入汤；保留为未来熟饭二次烹品类。
- `extra_pan_or_steam`：出现炒锅、蒸笼、烤箱、焯水、预蒸、分离装配或成品再拌；不得伪装成单锅电饭煲菜饭。
- `archive`：官方确实记录具名饭／米食，但缺份数、定量、液体、完整步骤，或来源只能证明身份；只保留档案，不进入当前轮替。

4. r121 已记录的 `蓮棗糯米飯`、`遇上烏龍油飯`、`魚酥米糕`、`番茄豆腸咖哩飯`、`強強聯手之雙色芋泥米糕`、`飄香奶飯` 本轮均排除，不重复计数。
