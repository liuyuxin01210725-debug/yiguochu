## 边界

- `direct_one_pot`：来源明确在同一锅/电锅/炊饭器中完成；不能从菜名推导电饭煲参数。
- `extra_pan_or_steam`：需要预炒、另锅、烤箱、蒸笼或分阶段投料；可以作为有出处资产，但不能宣传为一键电锅。
- `cooked_rice_second_cook`：来源以熟饭为前提再炒、浇汁、拌合或包裹；不得改写成生米同锅。
- `archive`：具名事实存在，但器具、步骤或主餐边界不够闭合；缺字段保持缺失。

## 不得发生的推断

1. 熟饭炒制/浇汁不得写成生米同锅，也不得加入电饭煲轮替池而隐去熟饭前提。
2. 另锅、烤箱、蒸笼、多阶段投料必须保留器具边界；来源没有电锅参数时不能推导。
3. 甜粥与主餐菜饭分层展示，不因都含“饭/粥”而混为同一品类。
4. 具名来源中的食材量可记录，但安全终点、营养和机型适配仍需独立核验。
5. 本 intake 只写研究资料，不修改 `catalog_version`、主 JSON、运行时代码，不部署。
