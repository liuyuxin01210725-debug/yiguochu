## 分类口径

- `direct_one_pot`：原文在同一锅中完成生米／米粥主过程；器具按原文记录，未把普通锅、砂锅或蒸锅推导成电饭煲。

- `extra_pan_or_steam`：需要另锅、焯水、预炒、蒸笼、烤箱或分离装配。

## 去重与边界结论

1. 本轮 32 条名称均通过当前 `r112/849` 主目录的 `canonical_name`／`aliases` 精确文本去重；本轮不重复抄录已存在的 `黃金海鮮粥`、`南瓜五穀飯`、`芋頭鮮蝦五穀蒸飯`、`焗南瓜海鮮糙米飯`、`番茄湯田園雜菜泡飯`、`西紅柿瓜湯西施飯`、`蒜蓉野菌雜菜石頭窩飯`、`胡蘿蔔海鮮飯`及三道香港煲仔飯。
2. 真实具名不等于可轮替：AFA 电子书中大量条目是儿童、孕妇或老人配餐，香港 EatSmart 中部分是饭团、饭浆网或多组件装配；这些条目均显式标为 `archive`，不提升为可照做菜谱。
3. 本轮最接近产品“一锅米饭主餐”的条目是：`海鮮煮飯`、`蛤蜊青菜湯飯`、`瓜仔雞湯飯`、`草魚湯飯`、`羅宋湯飯`、`鮮茄牛肉湯飯`、`蒜蓉貴妃蚌蒸五穀米`。其中只有原文明确的普通锅／蒸锅事实；没有任何条目凭来源自动获得普通电饭煲适配结论。
4. `cooked_rice_second_cook` 不得混入生米一锅轮替池。项目若将来开启“剩饭／熟饭二次烹”品类，应以具名、来源充分、器具边界明确为开启条件。
