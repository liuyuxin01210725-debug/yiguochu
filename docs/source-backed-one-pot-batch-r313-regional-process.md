# r313 区域来源工序补齐

基线为 `source-backed-one-pot-v1-20260810-global-r293`、923 条。本批不新增 canonical、不改变正式 72 道基础菜谱，也不把身份来源提升为 executable；只把三张原来没有 `cooking_sequence` 的身份卡补成“来源步骤 + 研究起步卡”。

| recipe_id | 来源补入的工序 | 仍缺字段 | 研究卡可见的起步字段 |
| --- | --- | --- | --- |
| `wulong-dingpot-sticky-rice-kongfan` | 武隆区政府原文写明鼎罐置于柴火/灶头上煮饭，鼎罐里可煮腊肉或糯米箜饭。 | 糯米浸泡、米水、配料克数、火候、总时长、安全 | 研究起步量、液体、至少四步、时间均标估算；保留鼎罐/柴火边界 |
| `changning-kas-dai-bamboo-rice` | 保山市政府原文写明卡斯傣族竹筒饭以竹筒蒸熟后食用。 | 竹筒规格、米态、米量、加水量、蒸制时间、安全 | 研究起步量、蒸锅水和蒸制时间均标估算；不换算普通电饭煲 |
| `yuping-dong-sticky-rice` | 玉屏县政府原文写明玉屏糯米饭在前一天晚上精心制作。 | 浸泡、蒸/煮方式、配料、液体、总时长、器具、安全 | 研究卡保留来源时间线，其余字段标估算/待核 |

研究卡的数字不是上述政府页面的原方定量；它们只用于让用户能先做一次并记录实际水量、时长和结果。来源事实与估算在页面中分色并分别标注。
