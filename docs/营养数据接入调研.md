# 中国食物成分表 — 数据接入调研（2026-06）

为「一锅出」接入权威营养数据做的决策调研。结论先行，细节附来源。

## 一句话结论
官方**只卖书、不给数据**（无 API / 无批量下载 / 无数据集售卖）。不存在"免费合法直接接"的路径。最务实组合：**USDA 免费 API 打底（可商用）+ 自购正版第6版书把中式特有食材补全校对**。

---

## 1. 更新机制：定期改版，不是动态数据库
- 每 ~8–10 年一大版。最新 = **《中国食物成分表 标准版（第6版）》**：第一册(植物性)**2018**、第二册(动物性)**2019**，北京大学医学出版社。
- 一次性导入一个版本即可，无需"实时同步"，也没有实时同步渠道。
- ⚠️ 网传"第6版2023更新"与所有一手书目(2018/2019)冲突，判定为错误信息，以 2018/2019 为准。
- "标准版 vs 代表值版"：不是两个版本；"代表值"是表内数据概念（检测平均值）。买标准版第6版、分册买即可。

## 2. 官方获取：拿不到结构化数据
- 官方在线平台 `nlc.chinanutri.cn/fq/`：约 1300 种食物 31 项营养，**只能逐条网页查，无导出、无 API**。
- 公共卫生科学数据中心 `phsciencedata.cn`：有结构化数据但是 **2002 旧版**，需注册申请。
- **无任何官方"结构化数据文件/API 授权"售卖渠道**。官方商业化路径=卖书。
- ⇒ 想要权威结构化数据，只能：买正版书 → 自己 OCR/录入数字化。

## 3. 第三方数据源（都是民间 OCR/录入版，质量+版权打折）
- **GitHub `Sanotsu/china-food-composition-data`**：第6版能量与一般营养成分 **1677 条 JSON**，含维生素/矿物质等 25+ 字段。但作者声明**"版权归原作者、仅供测试"=禁止商用**，且是视觉大模型 OCR 识别、**不保证准确**。→ 只能当原型加速器/比对底稿，不能作商用数据源。
- **CnOpenData**（商业，1700+，需联系，版本来源未明）。
- **TianAPI 营养成分接口**（~2000 种，便宜，但数据来源权威性弱）→ 适合兜底原型。

## 4. 版权红线（重要）
- 单个营养数字（某食材每100g多少蛋白）= **客观事实，不受著作权保护**。
- 但整本表的**选择与编排 = "汇编作品"，受著作权法保护**；官方亦强调其"经济社会价值"。
- 直接搬运书/OCR版的结构化数据（含食品编码、编排顺序）作商用 = **风险最高**；用声明禁商用的 GitHub 版尤其被动。
- 相对安全：把数值当事实用、**自建命名体系与数据组织、不照搬原书编码/编排**，保留"参考自公开来源"说明。
- **规模化/融资/上架前，值得花一次知识产权律师咨询费**确认边界。（以上非法律意见）

## 5. 替代 / 补充源
- **USDA FoodData Central**：完全免费、注册得 API key、**美国政府数据属公共领域可商用**。但**中式特有食材（丝瓜/腊肠/豆腐干/油菜/紫苏/豆豉）覆盖差**——适合通用食材兜底层，撑不起中式主数据。API: https://fdc.nal.usda.gov/api-guide/ ，批量CSV: https://fdc.nal.usda.gov/download-datasets/
- **薄荷健康 Boohee**：100万+食物、**中式覆盖最强**，企业合作/接口需商务谈价。https://www.boohee.com/boohee/cooperation
- Edamam（$299/月起）、Nutritionix（$1850/月起）：偏西餐、贵，不适合。

## 6. 方案对比

| 方案 | 合法性 | 成本 | 工作量 | 质量/覆盖 |
|---|---|---|---|---|
| **A 自购第6版书+自己数字化** | ✅最稳(数值=事实+自建编排;建议留律师咨询) | 书几百元 | **高**:OCR/录入+全量校对数千条,约1-2周人工 | ⭐⭐⭐⭐⭐ 权威/含微量/最贴中式 |
| **B USDA免费API + 中式食材人工补** | ✅可商用 | **0** | 中:补录丝瓜/腊肠等几十~上百项 | ⭐⭐⭐ 通用好,中式特有缺口大 |
| **C 薄荷健康商业授权** | ✅有授权最干净 | 需谈价 | **低**:对方给结构化数据 | ⭐⭐⭐⭐ 中式最全省事 |

## 7. 导入路径（若拿到一份合法结构化数据）
- **最现实格式：CSV（每100g可食部口径）**，典型列：食物名称/编码/可食部%/能量kcal/蛋白/脂肪/碳水/纤维/钠/钾/钙/镁/铁/锌/硒/维A/B1/B2/烟酸/维C/维E…
- 路径：CSV → 一次性导入脚本(单位归一化 μg/mg/g + 缺失值规整 Tr≠0) → 用**别名映射表**把成分表食材名挂到 app 菜谱食材 → **抽样人工校对数值**(OCR 来源尤其要核对小数点/单位)。
- 工作量：OCR来源 CSV 需全量抽检约 1-2 周；已校对的商业数据仅需字段映射+命名对齐约几天。

## 给非技术决策者的结论
1. **不能免费合法直接接**——官方只卖书；免费的 GitHub 版自己声明禁商用且 OCR 有错。
2. **最务实**：USDA 免费打底（通用、可商用）+ 自购正版第6版补中式特有食材并校对。
3. **要不要下载**：要我接的话，得给我一份**结构化 CSV/JSON**（纸书我用不了）。买正版书是合法权威的底气，但需先数字化。
4. **现阶段建议**：产品还在早期、命中率已 93%，**不必现在投这 1-2 周**。维持 USDA 逐条核实即可，等有真实用户/要规模化再系统接。
