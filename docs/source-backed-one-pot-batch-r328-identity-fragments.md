- 怀化薅菜饭：怀化市文旅局活动页确认三月三制作并供应薅菜饭，并记录一次活动供应 300 公斤糯米薅菜饭；没有家庭份数、米水比、火力或总时长。
- 盱眙咸肉菜饭锅巴：盱眙政府页面摘要把该技艺与柴火灶炒饭传统联系起来；没有家庭定量或时间，保留柴火灶/炒饭边界。
- 独龙族玉米饭：云南省社会科学院资料确认玉米饭为传统主食，并概述传统烹饪多为烧、烤、煮；没有玉米饭的具体米水比、火力、时间或现代电饭煲参数。
