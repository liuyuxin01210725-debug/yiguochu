## 每条卡的必填试做记录

队列不会自动填写厨房观察或真实旅程。每条卡都要求记录：

1. 实际称量的食材；
2. 实际液体或原器具水位线；
3. 锅具、机型和程序；
4. 开始、结束与焖置时间；
5. 成品质地及对应的安全终点；
6. Planner 旅程、过敏、禁忌和替换回归。

只有这些证据闭合后，才可以讨论从研究/预览层进入正式 Planner；本批没有伪造任何厨房或旅程证据。

`source-recipes.html` 的本机试做表单现在对应保存这 6 类记录：实际称量食材、实际液体、锅具/机型/程序、开始/结束耗时与份数、成品质地/安全终点、Planner 旅程/过敏/禁忌/替换回归。保存位置仍是当前浏览器的本地存储；导出的 JSON 需要人工复核后，才可作为正式化证据输入。
