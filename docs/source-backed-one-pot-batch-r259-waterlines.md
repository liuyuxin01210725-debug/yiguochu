# r259：同源水位线字段闭合

基线为 r258 / 923 条。本批不新增 canonical、不晋升 executable，只把同一官方页面已经明确写出的内锅水位线写入 `liquid_contract.kind=waterline`；水位线仍绑定原机型，不换算成跨机型毫升数。

闭合的 9 条：

- Tiger 羊栖菜糙米饭：Brown 米 2 线；
- Toshiba RCP-30R 梅香什菌炊饭、海鲜西班牙风炊饭、石锅拌饭风炊饭：白米水位 2；
- 象印台湾糙米高丽菜什锦饭：糙米水位 3；
- 象印台湾玉米鸡蓉糙米粥：稀饭水位 1；
- Panasonic 台湾金沙皮蛋香菇粥：粥（5分）水位 1；
- 象印台湾日式野菇鸡肉炊饭：白米刻度 2；
- Panasonic SR-PAA100 地瓜稀饭：五分稀饭水位。

所有记录仍为 `recipe_fact_checked`，并保留原机型、程序、后加料和安全缺口；不把水位线当作普通电饭煲的通用比例，也不因此进入生产轮替池。
