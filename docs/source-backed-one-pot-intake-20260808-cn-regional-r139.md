## 证据、器具与营养纪律

1. 来源写出“适量水”“比米高某厘米”或“同蒸”时，只保存原始表达；不把相对水位或同类经验换算成通用毫升比例。
2. 电饭煲来源仍要保留机型/程序边界；普通锅、罗锅、瓦罉、蒸笼和柴火不能互相推导。前段炒制、后段入锅或收汁属于连续流程，不能删成“全部食材直接放入电饭煲”。
3. 猪肉、禽肉、牛羊肉、火腿和海鲜的熟制终点必须另有安全来源或厨房验证；来源的口感描述不替代安全合同。
4. 只有地方名称或旅游菜单的条目继续停在 `identity_verified`/archive；不能因为“饭”“锅巴饭”“焖饭”字样而增加轮替数。
5. 蚕豆菜饭、肉粘饭和施甸火腿饭虽然营养角色较完整，但尚未闭合统一份量、液体、时间和跨机型适配，不应在本轮被标为 executable 或公开可照做。
