## 证据、器具与营养边界

1. 来源写“适量水”“比米高某厘米”或“同蒸”时，只保存原始表达；不把相对水位、经验容量或同类菜比例换算成通用毫升合同。
2. 电饭煲、罗锅、瓦罉、土灶、蒸笼和公共大锅是不同事实域。原器具来源不能推出电饭煲水位、程序、防糊底或投料时机；一切跨器具适配仍须独立来源或厨房验证。
3. “先炒—再焖/蒸—最后拌匀”、先煮鱼/鳝后焖饭、另锅炖肉等连续流程必须保留，不能为了增加 direct_one_pot 数量删掉前处理或把多锅流程伪装成一锅直投。
4. 猪肉、禽肉、牛羊肉、腊味和海鲜的熟制终点只引用独立安全来源或明确厨房记录；“焖熟”“蒸透”不自动等于统一温度或时间合同。
5. 营养结构不能以“有饭”作为合格证明。蔬菜、蛋白和主食关系只能按来源实际写出的食材记录；纯碳水、甜味节庆米食、身份名录仍停在 archive/identity，不进入 B 架。
