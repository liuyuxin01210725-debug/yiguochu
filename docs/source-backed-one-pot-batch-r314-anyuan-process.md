# r314 安远焖饭来源工序补齐

基线为 `source-backed-one-pot-v1-20260810-global-r293`、923 条。本批不新增 canonical、不改变正式 72 道基础菜谱，只把 `cn-jiangxi-ganzhou-anyuan-menfan` 的原文工序接入研究做法卡。

安远县政府饮食习俗原文给出三段顺序：

1. 生米下锅煮至半熟；
2. 倒去米汤并加盖；
3. 撤火，利用锅的余热焖熟。

来源没有固定米量、米汤体积、总时长、食品安全终点或电饭煲等价参数。页面研究卡仍会提供明确标注为“估算”的起步量、液体和时间，供用户做第一轮记录；不会把这些数字写进 canonical 合同。

来源：[安远县人民政府·风土人情](https://www.ay.gov.cn/ayzf/c103767/tt.shtml)。
