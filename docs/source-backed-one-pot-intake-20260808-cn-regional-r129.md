## 本轮结论

本轮继续核验中国大陆政府、地方志、文旅、文化馆和非遗直达页面，口径为“真实具名的米饭/菜饭/焖饭/抓饭/炊饭等主餐”，并严格区分一锅流程、分段熟制、另锅配饭、甜点、面食和仅身份档案。

严格去重后，**本轮没有可直接新增的 canonical**。直接核实到的官方页面主要是现有条目的证据升级；另有一条“八宝糯米饭”有直接正文但地域归属不足，和一条“肉油饭”只有官方 PDF 搜索摘要，均不进入主 JSON。因而 r129-CN 精确新增为 **0**，新增 B 试做架为 **0**。这不是搜索失败，而是避免把已有家族、泛称或未闭合来源重复包装成新菜。

## 证据与器具边界

1. 政府名录、文化馆和地方饮食文章只能证明页面明确写出的名称、地域、食材和流程；缺少的克数、米水比例、时间、安全终点必须保持 `null`，不能从相似菜拼接。
2. PDF 搜索摘要不等于直接读取原文。肉油饭在归档、页码、摘要校验完成前，最多是待核线索。
3. 铜锅、罗锅、瓦罉、蒸笼、土灶与电饭煲不是同一器具事实。来源没有转换参数时记 `not_adapted` 或 `source_limited`，不能推导程序、水位和防糊底。
4. “肉类或菜蔬”这类定义只支持组合概念，不允许任意替换；具体食材兼容性要有独立来源或后续厨房验证。
5. 熟饭二次烹、另锅配饭、粥、面食、甜点和小吃不能为了扩大菜单数而改写成一锅米饭主餐。
