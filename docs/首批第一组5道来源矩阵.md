## 一、判定规则

来源按事实范围分别记账：身份、食材、用量、液体、流程、器具、时间、安全。一个来源写明菜名，不等于它同时证明用量或做法；砂锅、土灶或炉上锅的参数，也不自动成为电饭煲参数。

遇到不同来源给出不同时间、液体或流程时，保留各自版本和器具边界，不取平均，不拼成第三套配方。只有固定批量、液体、关键流程、时间和安全均闭合，且冲突已解决，才可能进入 `executable` 审查。

## 四、来源冲突与裁决

### 手抓饭

```text
冲突事实：不同来源的器具、液体描述和时间不同。
来源 A 及其说法：于田电饭锅版泡米30分钟、煮肉10分钟、焖20分钟，但米为适量，“1:2”对象不清。
来源 B 及其说法：伊犁炉上锅版肉菜煮20分钟，下米后焖40分钟。
来源 C 及其说法：新疆自治区传统锅版羊肉汤小火1.5小时，汤面刚没过米，下米后焖30分钟。
更接近原产地/原技法的来源：三个来源都属于新疆政府资料，但描述的是不同版本和器具，不能互相覆盖。
仍需厨房验证的变量：固定米量、明确液体量、适配器具和完整总时间。
当前裁决：未解决；三版保持独立，不建立统一液体或时间合同。
```

### 腊味煲仔饭与冬菇滑鸡饭

```text
冲突事实：暂无直接数值冲突，但现有来源只支持煲仔饭家族过程，缺少固定配方。
来源 A 及其说法：地方资料说明瓦罉、丝苗米、高低火转换及配料类型。
来源 B 及其说法：广东地方标准说明七成熟投料、微火收水和锅巴形成。
来源 C 及其说法：赤坎资料补充浸米2小时与余温焗5分钟。
来源 D 及其说法：杨浦时报厨师示范给出200克水、中火8分钟和小火15分钟，但没有米重。
更接近原产地/原技法的来源：三者均只保留其明确写明的原器具事实。
仍需厨房验证的变量：固定批量、米液数值、完整时间；若以后做电饭煲版本，所有转换参数都必须实做。
当前裁决：原方身份与家族流程已确认；固定配方和家庭适配未解决。
```

## 五、下一步只补什么

1. 上海咸肉菜饭：找上海本地固定配方，优先补主要食材数值、明确液体和完整时间。
2. 腊味煲仔饭：找直接写明腊味固定批量、米水和完整时间的粤菜资料。
3. 手抓饭：先选定一个明确版本，补齐大米、液体和安全事实；不再混合三版。
4. 咖喱鸡肉饭：先找九阳官方勘误或同型号另一版说明书裁决 Slow cook 与 White rice 冲突，再补成品份数和完整时间；找不到就保持缺口。
5. 冬菇滑鸡饭：找直接写明该菜固定配方的粤菜来源，而不是继续用家族性煲仔饭资料代替。

时间盒到期时，只能缩小进入厨房验证的批次，不能把上述缺口改写成已完成。
