# r327：延边石锅拌饭熟饭/后拌工艺片段

基线：`source-backed-one-pot-v1-20260810-global-r293` / 923 条。

吉林省文化和旅游厅原文明确：石锅拌饭先使用米饭，再搭配肉类、鸡蛋、黄豆芽、菌菇和时令野菜，食用时把材料拌匀。本批只把这段来源工艺写入研究卡，明确它是熟饭/后拌流程，不将其改写成生米电饭煲一锅菜。

原文没有固定份数、食材克数、液体、总时长或安全终点，相关字段继续保持缺口；传统石锅边界继续保留。
