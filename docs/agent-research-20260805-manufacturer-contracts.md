# 厂商官方炊饭/米饭合同补充研究（2026-08-05）

本报告是独立研究记录，不是生产菜谱。只记录厂商自有页面中已经出现的真实标题、份量、液体、时间、程序和器具信息；不把下文事实写入 JSON、Ratio DSL、Planner 或运行时。所有条目暂定 `research_only`，进入目录前仍须按项目的来源、食材、安全、跨机型和实厨校准闸门复核。

## 口径、访问与去重

- `tier A`：厂商自有 HTML 页面，标题、份量、关键食材、液体、程序/时间和器具型号（或适用机型范围）可在同一页定位。
- `tier A-`：一手页面很完整，但仍有水位线而非毫升、型号范围较宽、或部分调味为“适量”等执行边界。
- `tier B`：一手页面仍可追溯，但液体总量、型号适配、预处理或安全终点至少一项未闭合；仅作研究候选。
- `access`：先用 `web-access` CDP 前置检查，再从浏览器打开官方页面并读取页面 DOM；随后以同一已确认 URL 做原始 HTML `curl -L` 复核（HTTP 200）。检索日为 2026-08-05。没有把搜索摘要当成证据。
- 去重基线：核对当前工作区的 `tools/data/rice-meal-catalog.v1.json`、`tools/data/rice-meal-collection.v1.json`、`tools/data/rice-cooker-source-evidence.v1.json`，并对照 source-backed 目录快照（119 条 recipe，合并后项目所称 176 条目录的名称/别名集合）。下列五个标题、官方 URL 和核心组合均未发现 exact duplicate；仅有米饭/炊饭家族层面的近邻，不视为同一道菜。

## 候选一：Tiger《サーモンときのこのピラフ》

- `URL`：<https://www.tiger-corporation.com/ja/jpn/feature/recipe/post116/>
- `locator`：页面顶部 `サーモンときのこのピラフ`；`調理時間 55分`；`材料 4人分 060/100サイズ`；步骤中“トマトジュース…白米の目盛3（180サイズは目盛6）まで水”；末尾 `このレシピに対応する製品` 型号列表。
- `固定份量`：4 人、米 3 杯；鲑鱼（鱼片）80 g；黄油 10 g；蘑菇/鸿喜菇/香菇/舞茸分别 2 个、1/4 包、1 片、1/4 包；胡萝卜 20 g、洋葱 1/8 个、蒜 1/2 瓣；鸡汤块 1 个；香叶 1 片。盐、胡椒、白酒和欧芹为“适量”。页面同时给 8 人 180 型号的成比例批量。
- `液体/程序/时间`：番茄汁 200 mL；再加水至“白米”刻度 3（180 尺寸为刻度 6）；将鱼和炒香蔬菜置于米上，选 `炊込み` 炊煮；总调理时间 55 分钟。番茄汁不是全部液体，最终水的毫升数没有给出，不能转换成跨机型米水比。

- `重复判断`：**否（exact duplicate 未发现）**。与目录中的新疆抓饭、象印番茄海鲜饭等仅共享“米饭/鱼或蔬菜”家族，不同标题、组合、来源和机器合同。

## 结论与边界

1. 本轮得到 5 条厂商一手候选，其中 Tiger 3 条、Panasonic 2 条；均来自日本官网，补足了已有中国大陆/台湾厂商页面研究中的“型号—刻度—时间”证据。
2. 最接近可执行合同的是 Panasonic NF-PC400《炊き込みごはん》与 Panasonic NF-AC1000/700 市售调味包版本（分别约 1 小时和 55 分钟，型号及液体均有明确语义），但两者都是压力锅/自动烹调器，不得静默迁移到普通电饭煲。
3. Tiger 3 条具备固定份量和总时间；其液体仍以机型水位线为核心，且官网明确不同产品份量可能不同。Tiger《炊込み中華おこわ》的泡汁量未闭合，优先级低于另两条。
4. `サーモンときのこのピラフ`、`はもごはん` 均涉及鱼类；来源没有项目所需的中心温度记录，入库前必须补安全终点、过敏原和鱼类状态。`はもごはん` 还需保留骨切提示，不能把鱧静默替换成普通鱼。
5. 所有条目都应保持 `research_only`/`planned`；本报告不授权新增 JSON、Ratio DSL、Planner、前端菜单或 production 部署。
