## 本轮结论

本轮继续按“真实具名的米饭/菜饭/焖饭/抓饭/炊饭等主餐、来源可直接打开、不是甜点/零食/面食、不得把另锅菜和米饭拼成一锅”的口径，复核了浙江、云南、山东、江苏、甘肃、安徽、广东、宁夏、陕西、新疆等官方或地方志来源。

精确去重后，**新增且尚未在 r126/历史 intake 中出现的 canonical 只有 3 条，均为身份级资料候选，没有一条达到 B 试做架**：

1. 义乌铜罐饭（浙江义乌）；
2. 江川铜锅饭（云南玉溪江川）；
3. 台州肉末炊饭（浙江台州）。

三条来源都能证明“名称/地域关联”，但没有同时闭合食材、用量、液体、流程和安全字段，故建议 `identity_verified`，不能写成可照做菜谱，也不能推成电饭煲做法。其余核到的官方页面以既有条目的证据升级、同家族变体或排除记录处理；本轮不凑数量、不修改主目录。

### 台州炊饭的器具边界补证

[《台州市路桥区志》在线原文第 714 页](https://dfz.zj.gov.cn/zlyz/ossfs/h5/ZS-K-331004-2014-001-0101/files/basic-html/page714.html)记载“炊饭用糯米浸 24 小时后放蒸笼上蒸熟”，并说明它是早餐摊店与豆浆、豆生一起出售的食品。该页支持“炊饭”的蒸笼/早餐边界，不支持肉末炊饭的具体配料，也不支持电饭煲适配，因此只作为候选的边界证据，不并入合同。

## 证据与器具纪律

1. “身份名录/名菜清单”只能证明名称和地域，建议状态为 `identity_verified`；不得从名录补写米水比例、克数、时间或安全终点。
2. 铜锅、瓦罉、罗锅、蒸笼和土灶是原始器具事实。来源没有电饭煲转换证据时，必须写 `not_adapted` 或 `source_limited`，不能推导电饭煲程序。
3. “往饭锅里一焖”可以支撑同锅流程线索，但不自动闭合批量、液体、时间和熟制安全合同；缺字段保持 `null`。
4. 肉菜另锅后配饭、熟饭二次焗/拌炒、糁饭/面食、甜点与零食，均不能拼成一锅米饭主餐。
5. 本轮所有来源均按实际证明范围记录；未把搜索摘要、转载或模型补全当作完整做法。
