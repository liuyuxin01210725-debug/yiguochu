## 本批 6 条既有卡片

1. `yecheng-jiucun-pilaf`：新疆人大相关页面写明九村抓饭培训现场演示并焖制，核心食材为山羊肉、胡萝卜；补入一条来源工序，未推导米量、水量或时间。
2. `yining-caipulao-pilaf`：伊宁市政府页面概括抓饭的米、羊肉、胡萝卜、葡萄干、洋葱、清油混合焖制，并说明菜朴劳以白菜、番茄、辣椒、粉条作为配食；保留配食不强行同锅。
3. `yining-asimantu-pilaf`：同一官方页面说明阿西曼吐每碗抓饭配五、六个薄皮肉馅包子；补入数量线索，包子保持成品配食边界。
4. `guizhou-buyi-flower-glutinous-rice`：国家民委页面写明把糯米染成五颜六色后做花糯米饭；补入染色→制饭工序，未补染料比例或蒸制合同。
5. `weihai-baomi-chazi-dry-rice`：威海市志页面写明玉米大碴子捞成苞米碴子干饭；补入“捞干饭”来源工序，未补水米比例。
6. `kuancheng-manchu-sorghum-rice`：宽城县政府页面写明高粱米的主要吃法是捞干饭；补入来源工序，未补水米比例。

## 证据边界

上述卡片仍不是 `fixed_batch` 或 `liquid_contract` 已闭合的正式执行方。研究页会继续给出 2 人份、米 300g、液体 450mL 等起步值，但每项标为“估算”，并保留来源器具/配食边界；这些值不进入 72 道正式生产菜谱，也不改变货架签署状态。
