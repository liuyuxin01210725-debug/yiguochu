## 证据与目录纪律

1. 仅有身份或文化名录的页面建议 `identity_verified`，不写固定批量、米水比例、时间或电饭煲程序。
2. 原器具为铜锅、瓦煲、竹筒、土灶或砂锅时，字段只能写 `not_adapted`/`source_limited`；任何电饭煲参数必须有独立来源或厨房实做证据。
3. 熟饭二次焗/拌炒、另锅预制肉汤、伴菜另锅完成的事实，不能与生米同锅流程拼成一份合同。
4. 本轮来源中若页面访问状态、定位行或合同范围不足，保留缺口；不把搜索摘录、转载或 AI 提示页面当作完整做法来源。
5. 本轮不修改主目录，因此不 bump catalog version，不新增 recipe_id，不改变 B 架数量。
