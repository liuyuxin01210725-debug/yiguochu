## 不得从本轮证据推导的内容

1. “适量水”“一瓶半”“没过羊肉”和对象不清的“1:2”保持 `null`；不得从同类菜、常识或另一城市版本换算液体合同。
2. 原器具只证明原器具：电饭煲、陶罐、瓦煲、土灶、蒸桶和竹筒不能互推水位、程序、防糊底或投料时机。
3. “约 10/20/30 分钟”“焖至熟”若只覆盖某一阶段，不能当总烹饪时间；制作标称也不能当电饭煲从启动到完成的运行时间。
4. 大批量传统方（例如 40 人份社饭）不能直接按人数比例压缩成家庭批量；需要同一版本的家庭份数或厨房实测记录。
5. 腊肉、猪肉、羊肉、虾米等动物性食材的安全终点不能由“蒸熟/焖熟”泛化；需要物种对应的独立来源或厨房实测。
