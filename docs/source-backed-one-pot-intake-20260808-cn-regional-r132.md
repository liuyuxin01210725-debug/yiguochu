## 证据与器具纪律

1. 非遗名录、节俗和地方美食介绍只证明其明确写出的名称、地域、食材或技法；没有克数、液体、时长和安全终点时保持缺省。
2. 生米一锅、阴米预处理、蒸笼分段熟制、熟饭炒拌、米团糍汤食、米粉蒸肉和另锅配饭是不同事实域，不能为扩大菜单数量合并。
3. 陶罐、铁锅、饭甑、蒸笼、柴火和文火慢炖均不能自动转换成电饭煲程序；无转换来源时记 `not_adapted` 或 `source_limited`。
4. 纯米、染色糯米或米+土豆不满足当前“碳水 + 蛋白质或膳食纤维”的主餐边界，不进入 B 架。
