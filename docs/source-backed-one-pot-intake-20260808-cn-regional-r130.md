## C. 证据与器具边界

1. 官方名录或地方民俗页只证明页面明确写出的名称、地域、食材和流程；缺少克数、液体、时间、安全终点时保持缺省，不能从相邻菜拼接。
2. 生米焖、蒸笼分段熟制、熟饭炒拌、米粉蒸肉、肉腹填米和肉菜另锅配饭是不同事实域；本轮不把它们合并为“一锅饭”。
3. 陶罐、铁锅、柴火、蒸笼和文火慢炖不能自动转换为电饭煲程序。没有转换来源时记录 `not_adapted` 或 `source_limited`。
4. 纯米+土豆或纯染色糯米属于纯碳水/节庆主食边界，除非另有同锅蛋白或蔬菜事实，不进入本产品的 B 试做架。
